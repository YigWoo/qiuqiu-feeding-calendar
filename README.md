# 球球辅食日历 V4（口感与安全优化版）

## 手机直接打开的网址

https://yigwoo.github.io/qiuqiu-feeding-calendar/

这不是代码页面。家人用手机浏览器打开后，默认看到当天安排；可点“前一天 / 后一天”或日期框查看任一天。

## 使用

- **老人查看**：直接打开网址，查看早餐、午餐、晚餐、食材图、质地、观察事项和当天安全提醒。
- **调整开始日期**：右上角“设置” → 修改“实际开始日期” → 保存。
- **当天暂停**：右上角“设置” → 选日期 → 写原因（可选）→ “记录暂停并顺延”。暂停日不消耗计划，下一天自动继续同一计划日。
- **分享给家人**：点“复制家人链接”，将当前开始日期和暂停记录一起写进链接。以后更新暂停后，请重新复制一次链接转发。

## V4 审查与优化内容

在不改动原计划日期、原定食材总量、油量或过敏原引入时序的前提下：

1. **起步更清晰**：第 1–3 天由“燕麦/多谷物”明确为“单一配方高铁婴儿米粉”，避免起步时成分不清。
2. **早期质地更稳妥**：早期鸡蛋明确为“全熟鸡蛋压成细末”、豆腐明确为“压成细碎泥”，不把碎块直接当作可吞咽质地。
3. **三餐期主食不再模糊**：把“软饭/软面/稠粥”改为“软饭、软面或稠粥（三选一）”，避免把三个主食混在一餐。
4. **逐日增加可执行提示**：每一天新增“更好吃的小建议”和“安全重点”；鱼、虾、坚果/芝麻等显示对应防噎/过敏原提醒。
5. **程序复核**：185 天日期连续；已检查的常见首次食材均有首次引入标注；未发现酸奶与谷物同餐、动物蛋白与果泥同餐、或谷物+水果+蔬菜同餐的强行混合问题。

## 文件说明

- `index.html`：已部署的网页源文件。
- `build_v4.py`：从上一个 V3 网页内嵌的已审查计划重建 V4 网页和 Excel 的脚本。
- `球球辅食逐日计划_审查优化V4_口感安全与网页版.xlsx`：可在 Excel 中查看和继续维护的 V4 计划表。

## 重要边界

- 每日克数是**提供目标**，不是必须吃完的处方；不强喂。
- 食物需坐稳、全程看护、软烂湿润、温热不烫；坚果/芝麻酱必须调稀，不能给整粒坚果或干粉。
- 出现呼吸困难、面唇舌肿、全身风团、反复呕吐等，应立即就医；普通不适或生病期，不引入新食材。
- 网页是静态页面：分享链接可同步某一刻的开始日期和暂停记录；它不含云端数据库，因此管理员更新后需要重新转发新链接。
